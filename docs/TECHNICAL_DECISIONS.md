# 技术决策记录 / Technical decisions

| 决策 | 选择 | 原因 | 代价与替代方案 |
|---|---|---|---|
| 数据层级 | GDC Level-3 SeSAMe beta | 开放、样本规模大、下载后可直接分析 | 不能重做IDAT级QC；严谨扩展可下载原始IDAT |
| 推断尺度 | M值检验，beta值报告效应 | M值统计性质更好，beta效应更直观 | 两种尺度需清楚区分 |
| 配对分析 | 患者内肿瘤−正常M值差 + limma | 直接利用90对配对结构，代码/结果一致 | 可进一步加入协变量或混合模型 |
| DMP阈值 | BH FDR <0.05 且 |Δβ|≥0.20 | 同时约束统计与生物效应 | 阈值依赖任务，应报告连续效应 |
| 富集背景 | 全部390,644个QC后CpG | 避免用全基因组基因作错误背景 | 注释与版本仍影响结果 |
| KEGG | 官方REST映射本地缓存 + gsameth | 保留探针数偏倚校正并可离线复现 | KEGG会更新，应记录缓存日期/校验值 |
| 数据划分 | 患者级train/val/test | 防止同一患者配对样本跨集合 | 单次划分方差大，需重复评估 |
| 特征选择 | 训练集limma Top 1,000 | 防止测试标签泄漏并统一各模型输入 | 1,000是超参数，需敏感性分析 |
| 缺失填补 | 训练集中位数 | 简单稳健且无验证/测试泄漏 | 可比较KNN/迭代填补，但需嵌套学习 |
| 阈值选择 | 验证集Youden指数 | 将测试集与阈值开发隔离 | 临床场景应按代价或目标敏感度设定 |
| 置信区间 | 患者级bootstrap | 保留同一患者多样本相关性 | 仅一个测试划分，不能替代外部验证 |
| Transformer token | 每条染色体内10个排序CpG/patch，末端padding | 消除跨染色体patch并保留紧凑输入 | 仍是稀疏监督筛选面板，不代表全基因组tokenization |
| 位置编码 | 无位置、顺序位置、染色体+坐标Fourier三种消融 | 直接检验基因组坐标信息的贡献 | 当前预训练收益依赖配置，不能声称普遍优势 |
| XGBoost调参 | 训练集内患者分组5折CV，以log-loss选择参数和轮数 | 修复旧模型`best_iteration=0`的不稳定性 | 仍需重复外层划分评估分割方差 |
| 外部验证 | GSE52865冻结特征、参数与TCGA验证阈值 | 防止用外部标签反复调参 | 队列较小且存在概率校准漂移，需更多外部队列 |

所有定量结论应能追溯到`results/`中的表格或`results/evaluation/`中的机器可读核对文件。
