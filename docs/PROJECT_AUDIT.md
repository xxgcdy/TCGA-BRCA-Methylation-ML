# 项目审计 / Project audit

审计日期：2026-10-28。审计范围为仓库代码、服务器保存的中间结果、模型预测文件与配置；不重新训练模型。

## 结论

项目已形成可信的“TCGA真实数据—生物信息学分析—泄漏控制建模—独立测试”闭环。患者级划分、训练集内特征筛选、训练集统计量填补以及四模型同测试集比较均通过程序化检查。当前最强证据是：869个QC后样本、25,975个可重复大效应CpG、2,986个高置信DMR，以及LASSO/RF在134个独立测试样本上的高AUC。

项目尚不能声称临床泛化或“大模型”能力。主要缺口是外部验证、重复患者级划分/嵌套交叉验证、自监督预训练和跨平台校准。

## 已程序化核对的证据

- 训练/验证/测试分别为604/131/134个样本，患者交集为0。
- 1,000个模型CpG唯一，按训练集limma原始P值排序；HDF5元数据明确记录为training-only选择。
- 四个模型使用完全相同的134个测试样本与标签。
- Transformer输入矩阵为869 × 1,000，训练集统计量填补后无缺失。
- 保存预测重新计算的AUC、平均精确率、准确率、敏感度和特异度与汇总表一致。
- 匿名逐样本预测和患者级bootstrap置信区间已公开于`results/evaluation/`。

机器可读核对结果见`results/evaluation/project_evidence_checks.json`。

## 科学分析审计

### 可靠部分

- 使用GDC开放的TCGA-BRCA HM450 Level-3 SeSAMe beta值，890个文件全部MD5通过。
- 技术重复先处理，再进行样本/探针缺失率、随机位点、常见CpG/SBE SNP和常染色体过滤。
- DMP在M值上推断、用beta值报告效应量；同时进行全队列与90对患者配对分析。
- 配对主分析实际采用每位患者肿瘤减正常的M值差，再做limma截距模型；公开脚本已与最终结果对齐。
- GO/KEGG使用全部QC后CpG作背景，并通过missMethyl校正芯片探针数偏倚。

### 需要谨慎解释

- Level-3数据不含原始IDAT，无法重新执行检测P值、染料偏倚和原始信号QC。
- 当前未显式应用独立的cross-reactive probe黑名单，也未校正批次、肿瘤纯度或细胞组成。
- 全队列DMP是描述性比较；样本不平衡和潜在混杂可能影响P值，因此与配对结果的一致性更具说服力。
- DMR“高置信”是按区域重叠、方向、CpG数和效应量筛选，不是严格一对一的共识区域。
- CpG到基因/通路的注释代表邻近或重叠，不能直接证明调控因果或通路激活。

## 机器学习审计

### 泄漏控制

- 正确：先按患者划分，再仅在训练集选择Top 1,000 CpG。
- 正确：验证/测试缺失值使用训练集中位数；标准化参数也仅从训练集估计。
- 正确：分类阈值在验证集确定，测试集只用于最终报告。
- 注意：LASSO内部CV之前已在整个训练集选择特征，因此内部CV分数不是完全嵌套估计；独立验证/测试不受此问题污染。

### 模型结果与不确定性

测试集中只有16个正常样本。LASSO和RF特异度0.9375均对应15/16，患者级bootstrap 95%区间约为0.79–1.00；Transformer/XGBoost为13/16，区间约为0.60–1.00。小数点后的模型排名不应被过度解释。

XGBoost保存对象显示`best_iteration=0`、`best_score=1`，且未保留evaluation log。验证集只有14个正常样本，可能导致早停选择不稳定。应通过重复患者级划分和嵌套调参复核，而不是据此断言XGBoost不适合本任务。

## Transformer实现审计

- 实际架构：1,000 CpG按染色体/坐标排序；10 CpG一个patch；100个patch；64维embedding；4头、2层encoder；78,017参数。
- 实际位置表示：可学习的顺序位置embedding + 染色体embedding，不是基因组距离感知的位置编码。
- 固定每10个CpG切块可能跨越染色体边界；patch使用第一个CpG的染色体标识。这是下一版应修正的明确实现限制。
- 仅运行一个随机种子，最佳epoch为1；当前结果证明模型可学习信号，但不足以证明稳定优势。
- 现有训练是监督分类，不是masked methylation预训练，不能称为甲基化基础模型。
