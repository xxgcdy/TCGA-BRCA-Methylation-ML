# P2：位置编码与自监督预训练计划

## 当前状态与是否迁移GPU

- 已核实本机GPU：NVIDIA GeForce RTX 5090 D，约24 GB显存。
- 当前本机Python为3.10，但安装的是CPU-only PyTorch，CUDA不可用。
- 完整869 × 390,644 beta矩阵与训练中间文件仍在Linux服务器；GitHub只保留汇总和匿名预测。
- 现有78k参数监督模型在8核CPU即可训练。仅把同一模型搬到5090不会自动增加科学价值。

**决策：暂不把“GPU迁移”本身当成果。** 先修正token/位置表示，定义自监督和少标签评价，再建立独立CUDA环境并迁移所需的最小数据集。GPU的价值在多种子、遮蔽预训练和消融并行，而不是重跑一个已有单种子模型。

## 先修正的模型问题

1. 在染色体内构建patch，禁止跨染色体边界；不足10个CpG时padding并使用attention mask。
2. 保留染色体embedding，增加坐标信息：绝对坐标的分桶/傅里叶特征，或注意力中的相对距离桶。
3. 比较三种位置方案：顺序位置、染色体内坐标、坐标+相对距离；其余参数固定。
4. 同时保留“不做训练集DMP筛选”的输入版本，否则监督筛选会弱化自监督学习的意义。

## 自监督任务

主任务采用masked methylation modeling：

- 独立CpG遮蔽与连续区域遮蔽各占一部分；避免模型仅靠邻近插值。
- 输入将被遮蔽beta替换为mask token；损失只在遮蔽位置计算。
- 首选连续beta的Huber/MSE损失；离散低/中/高甲基化交叉熵作为消融。
- 预训练数据只使用训练患者；若加入无标签外部样本，必须保证下游测试患者不进入预训练。

## 可证伪的实验矩阵

| 变量 | 设置 |
|---|---|
| 初始化 | 随机 / masked预训练 |
| 标签比例 | 10% / 25% / 50% / 100%训练患者 |
| 位置表示 | 顺序 / 坐标 / 坐标+相对距离 |
| 随机种子 | 至少5个 |
| 测试 | 固定内部测试 + 冻结外部队列 |
| 对照 | LASSO、RF、相同参数量MLP、现有Transformer |

主终点不是把内部AUC从0.98提高几个小数点，而是：预训练是否在少标签条件下降低方差、改善校准，并提升冻结外部队列性能。

## GPU环境验收

建立独立环境后必须记录并通过：

```text
torch.version.cuda != None
torch.cuda.is_available() == True
GPU name contains RTX 5090
一次小批量forward/backward无OOM且损失下降
```

同时保存环境锁定文件、GPU/驱动信息、配置、种子、训练曲线和最佳checkpoint的SHA256。未经这些验收，不在README写“GPU训练完成”。

## 停止规则

- 若预训练在至少5个种子和少标签条件下无稳定收益，保留负结果并优先做外部验证。
- 若内部提升而外部下降，按过拟合/域偏移解释，不通过外部标签反复调参。
- 只有当位置消融和预训练对照完成后，才讨论扩大模型参数量。
