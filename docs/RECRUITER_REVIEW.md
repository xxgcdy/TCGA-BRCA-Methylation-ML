# 招聘者快速审阅 / Recruiter review

## 60秒版本

这是一个真实公共队列上的DNA甲基化研究项目，而不是只调用分类器的教学Demo。候选人处理了GDC数据获取与校验、技术重复、QC、全队列/患者配对DMP、DMR、偏倚校正富集、患者级数据划分、传统模型和轻量Transformer，并公开了匿名预测与可复核指标。

## 最值得看的三点

1. **科学设计：** 90对患者配对分析与全队列结果的Δβ相关达到0.9924，减少了只依赖不平衡横断面比较的风险。
2. **工程与统计纪律：** 患者级划分、训练集内Top 1,000 CpG选择、训练统计量填补、验证集定阈值；自动检查确认集合无患者重叠。
3. **诚实的模型结论：** Transformer学到有效信号但未超过LASSO/RF；项目明确讨论样本量、任务线性可分、单次划分和位置编码限制。
